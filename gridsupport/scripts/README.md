# Scripts

The four sponsorship instructions and the fan contribution are exercised by LiteSVM tests. `docs/architecture/MOCK_USDC_SETUP.md` contains the prepared Devnet CLI workflow; no Devnet mint creation, wallet funding, deployment, or transaction seeding command has been executed. The local program keypair is generated at `target/deploy/gridsupport-keypair.json` and is ignored by Git; a new checkout must generate or supply a matching keypair before `anchor build` checks program IDs.

On the inspected machine, the working SBF build command is `anchor build --arch v0 --tools-version v1.54`. The default tools version v1.57 is incomplete in its local cache. `npm test` builds the local-mint SBF binary, runs the TypeScript Mocha + LiteSVM integration suite, restores the default SBF binary, verifies that the restored binary rejects the local mint, then runs the existing IDL regression tests. The restore step also runs when the integration suite exits with a failure. `npm run typecheck` checks all TypeScript tests without emitting files. For the existing Rust token tests, build with `anchor build --arch v0 --tools-version v1.54 -- --features local-test-mint` and run `cargo test --offline --features local-test-mint`, then rebuild without the feature before any reviewed deployment.

`start-local-fan-validator.sh <temporary-directory>` builds the approved local-test-mint SBF, writes a real six-decimal standard SPL mint fixture and random mint authority with `prepare-local-fan-fixture.mjs`, and loads the mint and program into a fresh isolated validator. Stop it with Ctrl-C to restore the default SBF. With the validator running, `GRIDSUPPORT_LOCAL_RPC=http://127.0.0.1:8899 GRIDSUPPORT_LOCAL_MINT_AUTHORITY=<temporary-directory>/mint-authority.json npm run test:local-validator` from `frontend/` executes Rider, Shop and Fan RPC workflows. See [the Step 5 local guide](../docs/architecture/STAGE4B_STEP5_LOCAL_GUIDE.md).
